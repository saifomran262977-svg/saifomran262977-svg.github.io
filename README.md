# الموقع الرسمي للمؤلف سيف بن عمران (أبو البراء المصري)
### دار الخلافة — مكتبة رقمية إسلامية

مرحباً بكم في المستودع الرسمي لموقع **دار الخلافة**، المنصة المخصصة لعرض ونشر المؤلفات والكتب الدينية للمؤلف **سيف بن عمران (أبو البراء المصري)**.

هذا الموقع مصمم ليكون واجهة عصرية، سريعة، ومستقرة تماماً على الهواتف المحمولة والكمبيوتر، مع التركيز على سهولة التصفح وإبراز المحتوى العلمي والشرعي.

---

## ✨ مميزات الموقع

- **تصميم فخم ولامع:** واجهة زجاجية (Glassmorphism) بألوان ذهبية وزرقاء مشعة.
- **أداء فائق وبدون تهنيج:** استخدام أكواد خفيفة (Vanilla JS) تضمن سرعة التصفح على الهاتف.
- **متوافق تماماً مع جميع الشاشات:** تصميم متجاوب (Responsive) يعمل بسلاسة على الجوال والتابلت والكمبيوتر.
- **وضعان للمظهر:** دعم الوضع الداكن (Dark Mode) والوضع الفاتح (Light Mode) مع حفظ تفضيل الزائر.
- **محتوى ديناميكي:** يتم بناء الكتب والإخوة وقائمة التنقل تلقائياً من ملف إعدادات واحد.
- **أزرار عائمة للتواصل:** للاتصال السريع والعودة إلى أعلى الصفحة.
- **شاشة تحميل أنيقة:** تمنح تجربة مستخدم احترافية عند فتح الموقع.

## 📁 هيكل الملفات

يتكون المشروع من 9 ملفات أساسية موزعة في الجذر الرئيسي للمستودع:

| الملف | الوصف |
| :--- | :--- |
| `index.html` | الصفحة الرئيسية (الواجهة الترحيبية). |
| `books.html` | صفحة المكتبة الكاملة (جميع المؤلفات). |
| `brothers.html` | صفحة الإخوة الموحدين (أعزهم الله). |
| `sources.html` | صفحة المصادر والمراجع المعتمدة. |
| `contact.html` | صفحة التواصل (واتساب، فيسبوك، إنستغرام، تيك توك). |
| `about.html` | صفحة التعريف بالمؤلف ورسالته. |
| `style.css` | ملف التصميم الرئيسي والألوان والحركات. |
| `config.js` | ملف الإعدادات والبيانات (الكتب، الأسماء، روابط التواصل). |
| `main.js` | ملف المحرك والتفاعلات (بناء الصفحات، القوائم، الحركات). |

> **ملاحظة:** تم إلغاء استخدام ملف `script.js` ومجلد `css` القديمين، ويمكن حذفهما من المستودع.

## ⚙️ كيفية التعديل والإضافة

الموقع مصمم ليكون سهلاً في التحديث. **لا تحتاج إلى تعديل ملفات HTML** لإضافة كتاب أو تغيير رقم هاتف.

كل ما عليك فعله هو فتح ملف **`config.js`** وتعديل البيانات التالية:

- **إضافة كتاب جديد:** أضف كائنًا جديدًا في مصفوفة `books` مع العنوان والرابط والأيقونة.
- **إضافة اسم أخ:** أضف الاسم في مصفوفة `brothers`.
- **تغيير رقم الهاتف:** عدّل قيمة `contactPhone`.
- **تحديث روابط التواصل الاجتماعي:** عدّلها مباشرة في `contact.html` (لأنها روابط ثابتة).

## 🚀 طريقة النشر (GitHub Pages)

هذا الموقع مستضاف مجاناً عبر خدمة **GitHub Pages**.

1. قم برفع جميع الملفات إلى المستودع (`main` branch).
2. اذهب إلى **Settings** > **Pages**.
3. في خيار **Source**، اختر `Deploy from a branch`.
4. في خيار **Branch**، اختر `main` والمجلد `/ (root)`.
5. اضغط **Save**.
6. سيصبح الموقع متاحاً على الرابط: `https://saifomran262977-svg.github.io/`
